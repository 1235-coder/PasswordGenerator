# 🔐 Password Generator CLI

A simple but powerful Python password generator with clipboard support, history tracking, and password strength evaluation. :D

---

## 🚀 Features

- Generate secure passwords
- Choose character types:
  - lowercase letters
  - uppercase letters
  - digits
  - symbols
- Password strength meter (Weak / Medium / Strong)
- Copy password to clipboard
- Save password history with timestamps
- CLI menu interface
